# float-fixed-numbers

Две независимые консольные утилиты на C++ для работы с числами в
нестандартных форматах на битовом уровне:

- **`float/`** — программная реализация арифметики чисел с плавающей точкой
  (по мотивам IEEE 754) для нескольких форматов, включая экзотические
  8-битные ML-форматы (`e5m2`, `e4m3fn`, `e2m1`).
- **`fixed/`** — арифметика чисел с фиксированной точкой (Q-формат, `A.B`)
  с поддержкой знака и разных режимов округления.

Обе программы принимают число(-а) в виде hex-представления битов и печатают
результат операции (или просто разбор числа) в консоль.

## Сборка

Зависимостей нет, нужен компилятор с поддержкой C++17.

```bash
g++ -O2 -std=c++17 -o float/float_app  float/main.cpp
g++ -O2 -std=c++17 -o fixed/fixed_app  fixed/main.cpp
```

## `float` — плавающая точка

### Поддерживаемые форматы (`fmt`)

| `fmt`     | Знак | Экспонента | Мантисса | Bias | Комментарий                              |
|-----------|:----:|:----------:|:--------:|:----:|-------------------------------------------|
| `h`       | 1    | 5          | 10       | 15   | half precision (IEEE 754 binary16)         |
| `s`       | 1    | 8          | 23       | 127  | single precision (IEEE 754 binary32)       |
| `e5m2`    | 1    | 5          | 2        | 15   | 8-битный ML-формат (аналог OCP FP8 E5M2)   |
| `e4m3fn`  | 1    | 4          | 3        | 7    | 8-битный ML-формат, без inf, свой код NaN  |
| `e2m1`    | 1    | 2          | 1        | 1    | 4-битный ML-формат (FP4)                   |

Арифметические операции (`+ - * / mad fma`) поддерживаются **только** для
форматов `h` и `s`; для `e5m2`/`e4m3fn`/`e2m1` доступен исключительно разбор
и печать числа (программа завершится с кодом ошибки и сообщением
`Operations not supported for this format`, если запросить операцию).

### Режимы округления (`rounding`)

| Значение | Режим                                              |
|----------|-----------------------------------------------------|
| `0`      | к нулю (truncate)                                    |
| `1`      | к ближайшему, «к чётному» при равном расстоянии (RNE)|
| `2`      | к `+∞`                                               |
| `3`      | к `-∞`                                               |

### Запуск

```bash
# Разбор и печать одного числа
./float_app <fmt> <rounding> <hex_bits>

# Бинарная операция: + - * /
./float_app <fmt> <rounding> <op> <hex_bits_a> <hex_bits_b>

# Тернарная операция: mad (a*b+c) или fma (a*b+c со слитным округлением)
./float_app <fmt> <rounding> <mad|fma> <hex_bits_a> <hex_bits_b> <hex_bits_c>
```

`rounding` обязателен во всех случаях (в том числе при простой печати числа),
даже если реально не используется.

### Примеры

```bash
$ ./float_app s 0 3f800000
0x1.000000p+0 0x3F800000

$ ./float_app h 0 3c00
0x1.000p+0 0x3C00

$ ./float_app s 0 + 3f800000 3f800000
0x1.000000p+1 0x40000000

$ ./float_app s 0 fma 3f800000 40000000 3f800000
0x1.800000p+1 0x40400000

$ ./float_app e5m2 0 00
0x0.0p+0 0x00

$ ./float_app e4m3fn 0 7f
nan 0x7F
```

### Формат вывода

```
[-]0x1.<мантисса в hex>p<экспонента> 0x<исходные биты в hex>
```

Специальные случаи:
- **Ноль:** `[-]0x0.0...0p+0 0x...`
- **Денормализованное число:** мантисса нормализуется (ведущая единица
  переносится в целую часть), экспонента вычисляется соответственно.
- **Бесконечность:** `[-]inf 0x...`
- **NaN:** `nan 0x...`

### Внутреннее устройство

- `My_float` хранит распакованные знак/экспоненту/мантиссу числа плюс
  параметры формата (число бит экспоненты/мантиссы, bias) — это позволяет
  единообразно работать с разными форматами через одни и те же функции.
- `classify()` определяет класс числа (`ZERO`, `DENORMALIZED`, `NORMALIZED`,
  `INFINITY_VAL`, `QUIET_NAN`, `SIGNALING_NAN`) с особыми правилами для
  `e4m3fn` (нет inf, свой единственный код NaN) и `e2m1` (нет inf/NaN вообще).
  Такие форматы всегда обрабатываются отдельными веточками, потому что
  расположение специальных значений в них отличается от IEEE 754.
- Все арифметические операции (`float_add/_sub/_mul/_div/_fma/_mad`) сначала
  обрабатывают особые случаи (NaN, inf, ноль) через `handle_special_*`, затем
  считают в расширенной точности (`uint64_t`) с дополнительными guard/round/
  sticky битами и в конце округляют по выбранному режиму (`should_round_up`).
- `float_fma` вычисляет `a*b+c` с одним округлением в конце (честный FMA),
  а `float_mad` — как последовательные `mul` и `add` с округлением между
  ними (что обычно даёт немного другой результат).

## `fixed` — фиксированная точка

Формат числа задаётся как `A.B`, где `A` — число бит под целую часть,
`B` — число бит под дробную (в тысячных, т.е. на печати всегда 3 знака после
точки), суммарно `A + B` бит, число хранится как знаковое дополнение до 2
(sign-extend по `A+B` битам). Обязательное условие: `A + B <= 32`.

### Режимы округления (`rounding`)

Те же 4 режима, что и в `float`: `0` — к нулю, `1` — к ближайшему чётному,
`2` — к `+∞`, `3` — к `-∞`.

### Запуск

```bash
# Разбор и печать одного числа
./fixed_app <A.B> <rounding> <hex_bits>

# Бинарная операция: + - * /
./fixed_app <A.B> <rounding> <op> <hex_bits_a> <hex_bits_b>
```

### Примеры

```bash
$ ./fixed_app 8.8 0 0180
1.500

$ ./fixed_app 8.8 0 ff80
-0.500

$ ./fixed_app 8.8 0 + 0180 0080
2.000

$ ./fixed_app 4.4 0 "*" 18 20
3.000

$ ./fixed_app 4.4 0 / 18 00
div_by_zero
```

### Формат вывода

```
[-]<целая часть>.<дробная часть в тысячных>
```

Деление на ноль обрабатывается отдельно и печатает `div_by_zero` вместо
результата (с кодом возврата `0`).

### Внутреннее устройство

- Число хранится как `A+B`-битное целое со знаком; `sign_extend()`
  досоздаёт знаковый бит до полных 64 бит для корректной арифметики.
- `get_parts()` переводит абсолютное значение в пару (целая часть, дробная
  часть в тысячных) плюс остаток и «половину знаменателя» — они нужны,
  чтобы определить, в какую сторону округлять дробную часть при печати.
- Округление при печати (`round_toward_zero/_nearest_even/_pos_inf/_neg_inf`)
  и округление результата `*`/`/` до сетки формата (`round_for_mul_and_div`)
  — это два разных этапа: сначала считается точный результат операции в
  расширенной точности, затем он один раз округляется до `A.B`-сетки, и
  отдельно (при печати) миллипредставление округляется до 3 знаков после
  запятой.
- `fixed_mul`/`fixed_div` считают в `int64_t`, чтобы избежать переполнения
  при умножении двух `A+B`-битных чисел (максимум 32 бита каждое).

## Ограничения

- Оба инструмента читают числа как «сырые» биты в hex (без `0x` или с ним —
  оба варианта поддерживаются), а не как десятичные значения — то есть
  сначала нужно самостоятельно закодировать число в нужном формате.
- `float`: арифметические операции реализованы только для `h` и `s`;
  для 8/4-битных ML-форматов доступна только печать разобранного числа.
- `fixed`: суммарная разрядность `A + B` не должна превышать 32 бит,
  иначе программа завершится с ошибкой (`Wrond A.B`, код возврата `2`).
- Обе программы не проверяют переполнение размера мантиссы при выводе
  сверх разумных входных данных (например, `A.B` с `A=0`/`B=0` не
  валидируется отдельно).
